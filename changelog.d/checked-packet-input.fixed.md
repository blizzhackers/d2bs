- **Checked packets for `getPacket()` and `sendPacket()`.** Both functions refuse an empty packet, a packet longer than 516 bytes, a size other than 1 to 4 in the size, value form and an `ArrayBuffer` passed with other arguments with a warning and `false`, and the game keeps running. `getPacket()` also refuses a packet the game can't read or one that is cut short, and passes on all the packets of an `ArrayBuffer` or none of them. `sendPacket()` returns `false` when the game doesn't take the packet, outside a game for example. A value that throws while it is converted stops the call with its error. A game event message whose player name fills its whole 16-character field keeps the game running and reaches `gameevent` listeners with the first 15 characters, a chat packet that doesn't fit its fields reaches the game without a `chatmsg` event, and an item packet too short for its item code reaches `itemaction` listeners with an empty code (or, under 14 bytes, with no event).
