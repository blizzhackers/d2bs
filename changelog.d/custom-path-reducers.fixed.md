- **Custom path reducers.** `getPath()` with reduction type 3 plans its path with your own `reject`, `reduce` and `mutate` functions across the current act's areas, returns an empty path when the destination can't be reached, and keeps the game running while one of your functions waits, for example in `delay()`. An error one of them throws reaches the script at that `getPath()` call, a script that runs out of memory there stops at that call, and the call throws when any of the three is missing.
