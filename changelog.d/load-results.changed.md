- **`load()` reports whether the script started.** `load()` returns `true` when the new script's thread started and `false` when the file is missing or the thread could not start, and `load()` and `script.send()` throw an error the script can catch for a value that can't be copied to another script (a function, or a game object such as a Unit), so a loaded script or a `send()` receiver gets the values it was sent.
