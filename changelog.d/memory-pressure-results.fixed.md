- **More calls safe under memory pressure.** A script that runs out of memory while D2BS builds a result for it in `getStat(-1)`, `getStat(-2)`, `getSkill(4)`, `getItems()`, `getDialogLines()`, `getControls()`, `getScripts()`, `getPath()`, `screenToAutomap()`, `automapToScreen()`, the array form of `getMouseCoords()` and `getTextSize()`, `control.getText()`, `area.exits`, an item's `prefixes`, `prefixnums`, `suffixes` and `suffixnums`, `Directory.getFiles()`, `Directory.getFolders()`, `File.read()` or `File.readAllLines()` stops at that call, as it would anywhere else, and the game keeps running. `setTimeout()` and `setInterval()` with extra arguments stop the same way, and a game packet, chat, item or copy-data event whose values can't be built is skipped.
