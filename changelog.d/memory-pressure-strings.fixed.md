- **Strings under memory pressure.** A script that runs out of memory while D2BS makes a string for it, such as `me.name`, `me.profile`, an item's `fname`, `code` or `description`, `getBaseStat()`, `getLocaleString()`, `md5()`, `FileTools.readText()`, `File.readAll()`, `File.readLine()` or a database column value, stops there, as it would anywhere else, and the game keeps running.
