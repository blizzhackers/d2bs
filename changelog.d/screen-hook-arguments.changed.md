- **Screen hook arguments.** `Frame`, `Box`, `Line`, `Text` and `Image` take any finite number for every number argument and property, dropping the fraction (the same result as `value | 0`; `color`, `opacity`, `font` and `zorder` keep the low 16 bits), so a computed value such as `x / 2` moves the hook. Assigning `null` or `undefined` to a screen hook's `click` or `hover` removes that handler, and assigning a value that is not a function keeps the current one.
