- **Steady screen hooks.** Each `Image` draws the file it names, `image.location` can be changed back and forth, a BMP that failed to load is read again the next time an `Image` names it (so a fixed file shows without restarting Diablo II), a truncated, top-down or empty BMP, or one whose header is cut short, simply leaves the `Image` blank, and several scripts can create images at the same time. A click function given to a `Box`, `Frame`, `Text` or `Image` constructor stays with its hook for as long as the hook exists, removed or collected `Text` and `Image` hooks free their text and file names, and hooks with a hover function clean up fully when removed or collected. Images, hook z-order and click handlers can be changed while hooks are on screen or being clicked, and a hook appears only once it is fully made; a `Text` or `Image` that runs out of memory fails at that call as other calls do, and Diablo II keeps running.
