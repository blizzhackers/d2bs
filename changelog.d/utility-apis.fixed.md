- **Dependable file, folder, hash, clipboard and socket functions.** `sha256()`, `sha384()` and `sha512()` return their hash, and `md5_file()` and the other file hashes hash a file's exact bytes, so they match other tools for files with Windows line endings and for files of any size, return null for a file that can't be read, and keep the game running for any path a script passes. `Folder.getFiles()` and `Folder.getFolders()` list only their own folder, even while other scripts list theirs, leave the game's working folder alone, list a folder that no longer exists as empty, and refuse a search pattern that names another folder's files. `dopen()` throws an error the script can catch for a folder name that is too long, isn't a string or isn't valid, and returns undefined when no name, or more than one argument, is passed. `FileTools.copy()` makes a byte-for-byte copy, keeps an existing target unless its third argument is `true`, leaves nothing behind when the source is missing or the copy fails, and, like `FileTools.remove()` and `FileTools.rename()`, returns `true` or `false` so a script can tell whether it worked. `FileTools.readText()` and `File.readAll()` refuse files of 256 MB or more with an error the script can catch, `File.read()` with a very large count returns the rest of the file and returns consecutive data across calls, reading a closed `File` throws "File is not open", `File.path` returns the full name, and a file name of 516 characters or more (after joining it to the script folder) is refused as an invalid name. `paste()` returns an empty string when the clipboard holds no text, `copy()` and `paste()` keep non-ASCII text intact, and `copy()` returns whether the text was placed. `socket.read()` returns everything one receive delivered (up to 10000 bytes) decoded as UTF-8 text, NUL characters included, `send()` reports failures, and sockets release their memory and network resources when closed. `sendDDE()` uses the mode you pass, so modes 1 (poke) and 2 (execute) work. A long quoted `-title` launch argument no longer stops the game from starting: the parser keeps at most 199 characters of a quoted argument.
